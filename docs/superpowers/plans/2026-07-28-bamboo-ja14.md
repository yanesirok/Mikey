# JA14 Bamboo Maps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the arena's procedural bamboo bark map and hand-drawn leaf-card atlas with maps derived from the Globe Plants JA14 photogrammetry pack, and move the near tier's geometric crowns onto cards — keeping every culm procedural.

**Architecture:** Nothing is instantiated. The pack contributes pixels only: a bark strip that `ArenaTextures.Bark()` loads instead of generating, and six atlas cells rendered offscreen from the pack's crown mesh at rebuild time. Two pre-existing bugs are fixed first, because without them the maps buy nothing: the bamboo mesh has no tangent stream while its material enables `_NORMALMAP`, and `Save()` stores normal maps as sRGB.

**Tech Stack:** Unity 6000.3.18f1, URP 17.x, linear colour space, C# Editor scripts under `Assets/Editor` (no asmdef — everything compiles into `Assembly-CSharp-Editor`). Python 3.11 + PIL for one-off asset extraction.

```csharp
    /// <summary>
    /// Writes a generated map as a native Texture2D asset.
    ///
    /// <paramref name="linear"/> must be true for anything that carries data rather than colour.
    /// It was false for every map here including the normals, which meant a flat texel
    /// (0.5, 0.5, 1.0) reached the shader as (0.214, 0.214, 0.920) and tilted every surface by
    /// about 37°. Colour space is a constructor argument, so a texture whose flag changed has to
    /// be recreated — reusing the asset silently keeps the old one.
    /// </summary>
    private static Texture2D Save(string name, int width, int height, Color32[] pixels,
                                  bool linear = false)
    {
        string path = Dir + name + ".asset";
        var tex = AssetDatabase.LoadAssetAtPath<Texture2D>(path);
        if (tex == null || tex.width != width || tex.height != height || tex.isDataSRGB == linear)
        {
            AssetDatabase.DeleteAsset(path);
            tex = new Texture2D(width, height, TextureFormat.RGBA32, true, linear);
            AssetDatabase.CreateAsset(tex, path);
        }
        tex.wrapMode = TextureWrapMode.Repeat;
        tex.filterMode = FilterMode.Trilinear;
        tex.anisoLevel = 8; // decking seen at a grazing angle is mip mush without it
        tex.SetPixels32(pixels);
        tex.Apply(true);
        EditorUtility.SetDirty(tex);
        return tex;
    }
```

- [ ] **Step 1: Extract and downsample the reference maps**

Create `tools/ja14_extract.py`:

```python
"""Pull the three bark maps out of the JA14 UNITY .unitypackage into Assets/Fight/Arena/Ref/.

The pack is 86 MB of HDRP shadergraphs and 4K sheets we do not use. A .unitypackage is a gzipped
tar of <guid>/{pathname,asset}; this reads the pathnames and copies only what the arena needs,
downsampled to the point where the error is below the strip's own noise floor (256x2048 costs
RMSE 1.997 against an inter-row noise of 2.80).

Usage:  python tools/ja14_extract.py <JA14_PhyllostachysNigraHenonis_UNITY.zip>
"""
import io, os, sys, tarfile, zipfile
from PIL import Image

Image.MAX_IMAGE_PIXELS = None
OUT = os.path.join(os.path.dirname(__file__), "..", "Assets", "Fight", "Arena", "Ref")

# source basename -> (destination, size)
WANTED = {
    "T_PhyllostachysNigraHenonisBark01_BC.png":   ("JA14_Bark_BC.png",   (256, 2048)),
    "T_PhyllostachysNigraHenonisBark01_N.png":    ("JA14_Bark_N.png",    (256, 2048)),
    "T_PhyllostachysNigraHenonisBark01_R.png":    ("JA14_Bark_R.png",    (256, 2048)),
    "T_PhyllostachysNigraHenonisLeaves01_BC.png": ("JA14_Leaves_BC.png", (1024, 1024)),
    "T_PhyllostachysNigraHenonisLeaves01_M.png":  ("JA14_Leaves_M.png",  (1024, 1024)),
    "MESH_JA14_PhyllostachysNigraHenonis_A_LOD2.fbx": ("JA14_Bamboo.fbx", None),
}


def members(package_bytes):
    """Yield (basename, bytes) for every asset inside the .unitypackage."""
    tar = tarfile.open(fileobj=io.BytesIO(package_bytes), mode="r:gz")
    paths, blobs = {}, {}
    for m in tar.getmembers():
        if not m.isfile():
            continue
        guid, _, leaf = m.name.partition("/")
        if leaf == "pathname":
            paths[guid] = tar.extractfile(m).read().decode().strip()
        elif leaf == "asset":
            blobs[guid] = tar.extractfile(m).read()
    for guid, path in paths.items():
        if guid in blobs:
            yield os.path.basename(path), blobs[guid]


def main(zip_path):
    os.makedirs(OUT, exist_ok=True)
    with zipfile.ZipFile(zip_path) as z:
        inner = next(n for n in z.namelist() if n.endswith(".unitypackage"))
        package = z.read(inner)

    written = 0
    for name, blob in members(package):
        if name not in WANTED:
            continue
        dest, size = WANTED[name]
        target = os.path.normpath(os.path.join(OUT, dest))
        if size is None:
            with open(target, "wb") as f:
                f.write(blob)
        else:
            im = Image.open(io.BytesIO(blob))
            # Alpha on Bark01_BC is an export border artefact — two rows of 242 — not a mask.
            im = im.convert("RGB").resize(size, Image.LANCZOS)
            im.save(target, optimize=True)
        print(f"{name} -> {dest} {size or 'verbatim'}")
        written += 1

    if written != len(WANTED):
        sys.exit(f"expected {len(WANTED)} assets, wrote {written}")


if __name__ == "__main__":
    main(sys.argv[1])
```

```csharp
using UnityEditor;
using UnityEngine;

/// <summary>
/// Import settings for the third-party reference assets under Fight/Arena/Ref.
///
/// Written as a postprocessor rather than into .meta files because three of the five maps carry
/// data, not colour, and the vendor ships all of them flagged sRGB. A wrong sRGB flag on an
/// opacity mask is invisible until the silhouette comes out fat — a 0.5 threshold decodes to
/// 0.214 — and a wrong one on a roughness map moves its mean from 0.469 to 0.187.
///
/// Nothing here is referenced by a material or a scene, so none of it ships in the player: these
/// are the sources the generated maps are baked from, read once per Rebuild Arena.
/// </summary>
internal sealed class ArenaRefImporter : AssetPostprocessor
{
    private const string RefDir = "Assets/Fight/Arena/Ref/";

    private void OnPreprocessTexture()
    {
        if (!assetPath.StartsWith(RefDir))
            return;
        var importer = (TextureImporter)assetImporter;
        importer.textureType = TextureImporterType.Default;
        // Only the base-colour sheets are colour. Normal, roughness and opacity are data.
        importer.sRGBTexture = assetPath.EndsWith("_BC.png");
        importer.isReadable = true;          // every one of these is read from the CPU at bake time
        importer.mipmapEnabled = false;      // sampled once per texel by hand, never by the GPU
        importer.wrapMode = TextureWrapMode.Repeat;
        importer.maxTextureSize = 2048;
        importer.textureCompression = TextureImporterCompression.Uncompressed;
    }

    private void OnPreprocessModel()
    {
        if (!assetPath.StartsWith(RefDir))
            return;
        var importer = (ModelImporter)assetImporter;
        // The pack's own materials are HDRP (HDLitMasterNode, _DiffusionProfileReferences) and
        // would arrive referencing a shader this project does not have.
        importer.materialImportMode = ModelImporterMaterialImportMode.None;
        importer.animationType = ModelImporterAnimationType.None;
        importer.importAnimation = false;
    }
}
```

- [ ] **Step 3: Write the failing ring-phase self-check**

Add to `ArenaTextures.cs`, just above `Bark()`:

```csharp
    /// <summary>
    /// The rings in the reference strip do not sit where the UV contract wants them. Rolling the
    /// strip by this fraction of its height is what lines them up; see the design doc for the
    /// measurement. Kept as a constant with a check beside it, because a re-export or a different
    /// crop moves it and nothing in a rendered frame would say so.
    /// </summary>
    private const float BarkRingRoll = 0.1020f;

    /// <summary>Mean value the bark albedo is renormalised to, in the same gamma space the
    /// procedural generator authored in. Its own mean was 0.72 base plus 0.11 of fibre.</summary>
    private const float BarkTargetValue = 0.83f;

    /// <summary>
    /// Fails loudly when the painted node rings drift out of phase with the geometric swell.
    /// <see cref="Bake.Tube"/> puts its swollen loop at v = (k + 0.5) / BarkNodesPerTile and the
    /// map has to paint its ring at the same place; half an internode out and a frame-edge culm
    /// carries two rows of nodes, one modelled and one printed.
    /// </summary>
    private static void CheckRingPhase(Color32[] albedo, int width, int height)
    {
        var rowMean = new float[height];
        for (int y = 0; y < height; y++)
        {
            float sum = 0f;
            for (int x = 0; x < width; x++)
                sum += albedo[y * width + x].r;
            rowMean[y] = sum / width;
        }

        for (int k = 0; k < BarkNodesPerTile; k++)
        {
            // v runs up the map, rows run down it.
            float target = (k + 0.5f) / BarkNodesPerTile;
            int centre = Mathf.RoundToInt((1f - target) * height);
            int span = height / (BarkNodesPerTile * 2);
            int darkest = centre;
            for (int d = -span; d <= span; d++)
            {
                int y = ((centre + d) % height + height) % height;
                if (rowMean[y] < rowMean[darkest])
                    darkest = y;
            }
            float actual = 1f - (darkest + 0.5f) / height;
            float error = Mathf.Abs(actual - target) * BarkNodesPerTile;
            if (error > 0.1f)
                Debug.LogError($"ArenaTextures: bark ring {k} sits {error:F3} of an internode " +
                               $"from its geometric node (v {actual:F4}, want {target:F4}). " +
                               $"BarkRingRoll needs remeasuring against the reference strip.");
        }
    }
```

```csharp
    /// <see cref="BarkNodesPerTile"/> internodes, so the painted rings line up with the geometric
    /// ones on the frame-edge culms instead of drifting into a second, offset row of nodes.</summary>
    public const float BarkNodeSpacing = 0.34f;
    /// <summary>Three, not the six the drawn map used: the reference strip carries exactly three
```

Replace the whole body of `Bark()` (`ArenaTextures.cs:119-177`):

```csharp
    /// <summary>
    /// Bamboo bark, from a photographed culm rather than from noise.
    ///
    /// Three things arrive from the reference and one does not. The fibre, the node rings and
    /// their waxy collars come from the photograph; the roughness comes from its R map, inverted
    /// into smoothness. Occlusion does not exist in the pack at all, so it is derived from the
    /// albedo's own luminance — which puts the dip exactly where the node scar already is, the
    /// same place the drawn map put it by formula.
    ///
    /// The albedo is taken to a pure grey and renormalised. <c>Arena.shader</c> multiplies the
    /// base map by the vertex colour, and the vertex colour carries the whole tonal ladder
    /// between tiers; a green photograph multiplied by a green tint crushes the far tiers and
    /// re-saturates the haze the ladder exists to build.
    /// </summary>
    public static Surface Bark()
    {
        Texture2D srcColour = LoadRef("JA14_Bark_BC");
        Texture2D srcNormal = LoadRef("JA14_Bark_N");
        Texture2D srcRough = LoadRef("JA14_Bark_R");
        if (srcColour == null || srcNormal == null || srcRough == null)
            return default;

        int width = srcColour.width, height = srcColour.height;
        if (srcNormal.width != width || srcNormal.height != height ||
            srcRough.width != width || srcRough.height != height)
        {
            Debug.LogError($"ArenaTextures: the three bark references disagree on size — " +
                           $"BC {srcColour.width}x{srcColour.height}, " +
                           $"N {srcNormal.width}x{srcNormal.height}, " +
                           $"R {srcRough.width}x{srcRough.height}.");
            return default;
        }

        Color32[] srcC = srcColour.GetPixels32();
        Color32[] srcN = srcNormal.GetPixels32();
        Color32[] srcR = srcRough.GetPixels32();

        var albedo = new Color32[width * height];
        var normal = new Color32[width * height];
        var mask = new Color32[width * height];

        // Rec.709 in the photograph's own gamma space: the arena authors every map in gamma and
        // lets ToColor32(c.linear) do the one conversion. Matching that convention matters more
        // than being right about it — every colour constant in the arena was tuned against it.
        var luma = new float[width * height];
        float sum = 0f;
        for (int i = 0; i < luma.Length; i++)
        {
            luma[i] = (0.2126f * srcC[i].r + 0.7152f * srcC[i].g + 0.0722f * srcC[i].b) / 255f;
            sum += luma[i];
        }
        float gain = BarkTargetValue / Mathf.Max(sum / luma.Length, 1e-4f);

        // Rolled so the printed rings land on the geometric ones. Measured, not guessed, and
        // checked below.
        int roll = Mathf.RoundToInt(BarkRingRoll * height);

        for (int y = 0; y < height; y++)
        {
            int sy = ((y - roll) % height + height) % height;
            for (int x = 0; x < width; x++)
            {
                int i = y * width + x, s = sy * width + x;

                float value = Mathf.Clamp01(luma[s] * gain);
                albedo[i] = ToColor32(new Color(value, value, value).linear);

                // DirectX green: at every one of the three rings the reference reads below 128
                // above the ring and above 128 below it, which is the Y-down polarity for a
                // raised ridge. Unity wants Y-up.
                normal[i] = new Color32(srcN[s].r, (byte)(255 - srcN[s].g), srcN[s].b, 255);

                // g = occlusion, a = smoothness. Occlusion from the albedo's own luminance,
                // ranged to the 0.64..1 the drawn map authored; the node scar is the darkest
                // band in the photograph, so the dip lands on the node for free.
                float occlusion = Mathf.Lerp(0.64f, 1f, Mathf.Clamp01(luma[s] * gain));
                // The pack's R map is roughness — 155-162 over the sheath scar, 106-113 over the
                // waxy collar below it, which is the physically correct polarity.
                float smooth = 1f - srcR[s].r / 255f;
                mask[i] = new Color32(0, (byte)(occlusion * 255f), 0, (byte)(smooth * 255f));
            }
        }

        CheckRingPhase(albedo, width, height);

        return new Surface
        {
            Albedo = Save("T_Bark", width, height, albedo),
            Normal = Save("T_Bark_N", width, height, normal, linear: true),
            Mask = Save("T_Bark_M", width, height, mask),
        };
    }

    /// <summary>A third-party reference map, or null with a loud error. These live outside the
    /// player build: nothing but this file and the crown baker ever reference them.</summary>
    private static Texture2D LoadRef(string name)
    {
        string path = Dir + "Ref/" + name + ".png";
        var tex = AssetDatabase.LoadAssetAtPath<Texture2D>(path);
        if (tex == null)
            Debug.LogError($"ArenaTextures: {path} is missing — run tools/ja14_extract.py.");
        return tex;
    }
```

```csharp
using UnityEditor;
using UnityEngine;
using UnityEngine.Rendering;
using UnityEngine.Rendering.Universal;

/// <summary>
/// Renders the JA14 crown mesh into square RGBA buffers for the leaf-card atlas.
///
/// The pack ships one flat leaf sheet — three blades on a stem, fanning upward — and the atlas
/// needs four different silhouettes plus two near-crown ones, including a dense mass with no
/// readable individual leaves for the tier at thirty units. Rotating one photograph does not
/// produce those. Rendering the actual crown from six framings does, for the cost of six camera
/// renders per Rebuild Arena.
///
/// The plant is instantiated a kilometre above the arena rather than on a private layer: the
/// scene is open and full of geometry while this runs, and a tight near/far plane at y = 10000
/// excludes all of it without touching the layer table.
/// </summary>
public static class BambooCrownBake
{
    private const string RefDir = "Assets/Fight/Arena/Ref/";
    private const string ModelPath = RefDir + "JA14_Bamboo.fbx";

    /// <summary>Rendered at this multiple of the cell and box-filtered down. Supersampling rather
    /// than MSAA, because the matte below has to average cleanly and a resolved 4x edge does
    /// not give enough levels for a leaf tip.</summary>
    private const int Supersample = 4;

    /// <summary>Mean value the baked cells are renormalised to, in the gamma space the drawn
    /// cells authored in — their own tints run 0.66 to 0.98 with a mean near this.</summary>
    private const float LeafTargetValue = 0.82f;

    /// <summary>Where the camera stands and how much of the crown it frames.</summary>
    public readonly struct Pose
    {
        public readonly int Cell;
        public readonly float Yaw;    // degrees around the plant
        public readonly float Pitch;  // degrees above the horizon
        /// <summary>Fraction of the crown's height the frame spans. 1 puts the whole plant in the
        /// cell and every leaf under a pixel — which is what the far tier wants; 0.35 fills the
        /// cell with a few branches, which is what a crown six metres from the lens wants.</summary>
        public readonly float Fill;

        public Pose(int cell, float yaw, float pitch, float fill)
        {
            Cell = cell;
            Yaw = yaw;
            Pitch = pitch;
            Fill = fill;
        }
    }

    /// <summary>Cells 0-2 are the mid tier's readable fans, 3 is the far tier's dense mass,
    /// 7 and 8 are the near tier's crowns. 4-6 are bank grass and stay drawn.</summary>
    public static readonly Pose[] Poses =
    {
        new Pose(0, 25f, 8f, 0.70f),
        new Pose(1, 140f, 12f, 0.70f),
        new Pose(2, 255f, 4f, 0.70f),
        new Pose(3, 70f, 10f, 1.00f),
        new Pose(7, 200f, 6f, 0.35f),
        new Pose(8, 320f, 14f, 0.35f),
    };

    private static readonly Vector3 Stage = new Vector3(0f, 10000f, 0f);

    /// <summary>
    /// Renders one pose. <paramref name="rgb"/> receives unpremultiplied colour already carried
    /// into the arena's authoring convention; <paramref name="coverage"/> receives alpha in 0..1
    /// for the radii pass, which measures the CPU buffer and not the texture. Returns false with
    /// a logged error if anything is missing, so the atlas can fall back to drawing the cell.
    /// </summary>
    public static bool Render(in Pose pose, int size, Color32[] rgb, float[] coverage)
    {
        GameObject model = AssetDatabase.LoadAssetAtPath<GameObject>(ModelPath);
        Texture2D sheet = Composite();
        if (model == null || sheet == null)
        {
            if (model == null)
                Debug.LogError($"BambooCrownBake: {ModelPath} is missing — run tools/ja14_extract.py.");
            return false;
        }

        GameObject instance = null;
        GameObject rig = null;
        Material material = null;
        RenderTexture target = null;
        Texture2D readback = null;
        RenderTexture previous = RenderTexture.active;
        bool fog = RenderSettings.fog;

        try
        {
            instance = (GameObject)PrefabUtility.InstantiatePrefab(model);
            instance.hideFlags = HideFlags.HideAndDontSave;
            instance.transform.position = Stage;

            if (!IsolateCrown(instance, out Bounds crown))
                return false;

            material = new Material(Shader.Find("Universal Render Pipeline/Unlit"))
            {
                hideFlags = HideFlags.HideAndDontSave,
            };
            material.SetTexture("_BaseMap", sheet);
            material.SetFloat("_Surface", 0f);   // opaque queue…
            material.SetFloat("_AlphaClip", 1f); // …with a clip, so the matte below stays linear
            material.SetFloat("_Cutoff", 0.5f);
            material.SetFloat("_Cull", (float)CullMode.Off);
            material.EnableKeyword("_ALPHATEST_ON");
            foreach (MeshRenderer r in instance.GetComponentsInChildren<MeshRenderer>())
                r.sharedMaterial = material;

            rig = new GameObject("BambooCrownBake") { hideFlags = HideFlags.HideAndDontSave };
            Camera cam = rig.AddComponent<Camera>();
            Frame(cam, crown, pose);

            // The arena is a foggy grove and URP fog applies in the unlit pass too. Baked into a
            // card it would fog the leaves twice: once here, once by the scene the card sits in.
            RenderSettings.fog = false;

            int render = size * Supersample;
            target = new RenderTexture(render, render, 24, RenderTextureFormat.ARGB32)
            {
                antiAliasing = 1, // supersampling does this job; MSAA here would double-resolve
            };
            readback = new Texture2D(render, render, TextureFormat.RGBA32, false);

            Color32[] overBlack = Shoot(cam, target, readback, Color.black);
            Color32[] overWhite = Shoot(cam, target, readback, Color.white);
            Matte(overBlack, overWhite, render, size, rgb, coverage);
            return true;
        }
        finally
        {
            RenderSettings.fog = fog;
            RenderTexture.active = previous;
            if (readback != null) Object.DestroyImmediate(readback);
            if (target != null) { target.Release(); Object.DestroyImmediate(target); }
            if (material != null) Object.DestroyImmediate(material);
            if (rig != null) Object.DestroyImmediate(rig);
            if (instance != null) Object.DestroyImmediate(instance);
        }
    }

    /// <summary>
    /// Turns off the culm and reports the bounds of what is left.
    ///
    /// The FBX carries bark and leaves as two children named MI_LOD2 and MI_LOD2_001, and with
    /// materialImportMode None there are no material names to tell them apart. Vertex count does:
    /// the crown outnumbers the culm 4.6 to 1 on the adult LOD2 and 2 to 1 on the smallest mesh
    /// in the pack. A photographed culm inside the card would double up on the procedural one the
    /// card hangs from.
    /// </summary>
    private static bool IsolateCrown(GameObject instance, out Bounds crown)
    {
        crown = default;
        MeshFilter[] parts = instance.GetComponentsInChildren<MeshFilter>();
        if (parts.Length != 2)
        {
            Debug.LogError($"BambooCrownBake: {ModelPath} has {parts.Length} meshes, expected 2 " +
                           $"(one bark, one leaves).");
            return false;
        }

        int leaves = parts[0].sharedMesh.vertexCount >= parts[1].sharedMesh.vertexCount ? 0 : 1;
        parts[1 - leaves].gameObject.SetActive(false);
        crown = parts[leaves].GetComponent<MeshRenderer>().bounds;
        return true;
    }

    /// <summary>Points the camera at the crown from the pose's angle, far enough back that
    /// <see cref="Pose.Fill"/> of the crown's height spans the frame.</summary>
    private static void Frame(Camera cam, Bounds crown, in Pose pose)
    {
        const float fov = 24f;
        float span = Mathf.Max(crown.size.y * pose.Fill, 0.01f);
        float distance = span * 0.5f / Mathf.Tan(fov * 0.5f * Mathf.Deg2Rad);

        Quaternion rotation = Quaternion.Euler(pose.Pitch, pose.Yaw, 0f);
        cam.transform.position = crown.center - rotation * Vector3.forward * distance;
        cam.transform.rotation = rotation;

        cam.fieldOfView = fov;
        cam.nearClipPlane = Mathf.Max(distance - crown.size.magnitude, 0.01f);
        cam.farClipPlane = distance + crown.size.magnitude;
        cam.clearFlags = CameraClearFlags.SolidColor;
        cam.allowMSAA = false;
        cam.allowHDR = false;

        var data = cam.GetUniversalAdditionalCameraData();
        data.renderPostProcessing = false; // or the scene's grade tonemaps the atlas
        data.renderShadows = false;
        data.requiresColorOption = CameraOverrideOption.Off;
        data.requiresDepthOption = CameraOverrideOption.Off;
    }

    private static Color32[] Shoot(Camera cam, RenderTexture target, Texture2D readback, Color clear)
    {
        cam.backgroundColor = clear;
        cam.targetTexture = target;
        cam.Render();
        cam.targetTexture = null;

        RenderTexture.active = target;
        readback.ReadPixels(new Rect(0, 0, target.width, target.height), 0, 0);
        readback.Apply();
        return readback.GetPixels32();
    }

    /// <summary>
    /// Box-filters both renders down to the cell and recovers the matte.
    ///
    /// Two backgrounds, not one alpha channel: URP is configured with
    /// m_AllowPostProcessAlphaOutput 0 and nothing guarantees usable alpha out of an ARGB32
    /// target. Where the plant covers a texel both renders agree; where it does not they differ
    /// by exactly one, so their difference is the background's share of the texel.
    ///
    /// The division by coverage is not optional. Writing the over-black render as the colour
    /// leaves every rim texel premultiplied toward black, and the mip chain then pulls the whole
    /// leaf edge dark — the failure the fill-the-transparent-texels rule in ArenaTextures exists
    /// to prevent.
    /// </summary>
    private static void Matte(Color32[] black, Color32[] white, int render, int size,
                              Color32[] rgb, float[] coverage)
    {
        int step = render / size;
        var value = new float[size * size];
        float sum = 0f;
        int covered = 0;

        for (int y = 0; y < size; y++)
            for (int x = 0; x < size; x++)
            {
                float br = 0f, bg = 0f, bb = 0f, diff = 0f;
                for (int sy = 0; sy < step; sy++)
                    for (int sx = 0; sx < step; sx++)
                    {
                        int s = (y * step + sy) * render + x * step + sx;
                        br += black[s].r; bg += black[s].g; bb += black[s].b;
                        diff += (white[s].r - black[s].r) + (white[s].g - black[s].g) +
                                (white[s].b - black[s].b);
                    }

                float samples = step * step;
                float a = Mathf.Clamp01(1f - diff / (samples * 3f * 255f));
                int i = y * size + x;
                coverage[i] = a;
                if (a < 0.004f)
                    continue;

                // Unpremultiplied, then straight to a value: the vertex colour carries the hue.
                float r = br / (samples * 255f * a);
                float g = bg / (samples * 255f * a);
                float b = bb / (samples * 255f * a);
                value[i] = 0.2126f * r + 0.7152f * g + 0.0722f * b;
                sum += value[i];
                covered++;
            }

        float gain = covered > 0 ? LeafTargetValue / Mathf.Max(sum / covered, 1e-4f) : 1f;
        for (int i = 0; i < value.Length; i++)
        {
            if (coverage[i] < 0.004f)
                continue;
            float v = Mathf.Clamp01(value[i] * gain);
            // The same one gamma step every drawn cell goes through: the arena authors in gamma
            // and stores the .linear of it in an sRGB texture. Wrong, and uniform, and every
            // colour constant in this scene was tuned against it.
            byte b8 = (byte)(Mathf.Clamp01(new Color(v, v, v).linear.r) * 255f);
            rgb[i] = new Color32(b8, b8, b8, 255);
        }
    }

    /// <summary>
    /// JA14 keeps colour and opacity in separate files and no URP shader samples two maps for one
    /// alpha, so they are combined once into a throwaway RGBA texture.
    /// </summary>
    private static Texture2D Composite()
    {
        var colour = AssetDatabase.LoadAssetAtPath<Texture2D>(RefDir + "JA14_Leaves_BC.png");
        var opacity = AssetDatabase.LoadAssetAtPath<Texture2D>(RefDir + "JA14_Leaves_M.png");
        if (colour == null || opacity == null)
        {
            Debug.LogError($"BambooCrownBake: {RefDir}JA14_Leaves_BC.png or _M.png is missing — " +
                           $"run tools/ja14_extract.py.");
            return null;
        }
        if (colour.width != opacity.width || colour.height != opacity.height)
        {
            Debug.LogError($"BambooCrownBake: leaf colour is {colour.width}x{colour.height} but " +
                           $"its mask is {opacity.width}x{opacity.height}.");
            return null;
        }

        Color32[] c = colour.GetPixels32();
        Color32[] m = opacity.GetPixels32();
        for (int i = 0; i < c.Length; i++)
            c[i].a = m[i].r; // the mask is one channel triplicated — R, G and B are bit-identical

        var sheet = new Texture2D(colour.width, colour.height, TextureFormat.RGBA32, true, false)
        {
            hideFlags = HideFlags.HideAndDontSave,
            wrapMode = TextureWrapMode.Clamp,
        };
        sheet.SetPixels32(c);
        sheet.Apply(true);
        return sheet;
    }
}
```

## Not in this plan

- **Alpha-to-coverage.** `Arena.shader:213` returns `half4(color, 1.0)`, so the sample mask is always all-ones and `AlphaToMask` degenerates to plain MSAA — the comment at `:87-89` promises something that does not happen. Returning `baseTex.a` touches every material on the shader, including the opaque ones, and belongs in its own change.
- **The albedo and mask double-gamma.** Real, documented in the spec, and out of scope: fixing it re-tunes every colour constant in the arena.
- **Device measurement.** 32 760 opaque triangles become 390 clipped cards at renderQueue 2450. On a mobile TBDR that trades vertex cost for overdraw, and `BambooArena.cs:1754-1755` says fill rate is what a grove runs out of first. The triangle win is arithmetic; the frame win is not, and only a phone settles it.
