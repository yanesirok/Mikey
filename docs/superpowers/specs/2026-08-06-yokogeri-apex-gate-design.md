# Yoko geri: зона только у верхушки взмаха

**Дата:** 2026-08-06
**Статус:** одобрено к реализации (дизайн)
**Дополняет:** `2026-08-06-yokogeri-zones-design.md`
**Тема:** yoko geri gedan засчитывает всё подряд — подъём колена и любой мах
проходят как правильный удар.

## Улики (сессия 07:41, граунд-трус: сначала настоящие удары, потом подъёмы колена)

- Реплей текущей логики: 7 взмахов → 7 зачётов, 0 отказов.
- Причина: зона проверяется на любом кадре фазы «нога поднята», включая
  гистерезисный хвост опускания (подъём 0.25…1.0). Опускающаяся нога — прямой
  маятник: в каждом взмахе есть 2–5 кадров с коленом 175–179° ниже таза на
  подъёме 0.3–0.93. Для гэдана этого достаточно — любой взмах получает зону.
- Юнит-тест замаха это не ловил: в нём замах завершается мгновенно, без
  медленного опускания с распрямлением.

## Фикс

Зона засчитывается только у верхушки взмаха: к условию выпрямленности
добавляется **сглаженный подъём ≥ порога начала цикла** (`liftedAt`, стопа выше
колена опорной ноги). Транзитные кадры опускания отсекаются.

- **`LegLiftCycle`**: открыть порог свойством `public float LiftedAt => _liftedAt;`
  — единственный источник значения, анализатор не хранит копию.
- **`YokoGeriAnalyzer.ProcessFrame`**: условие сэмплирования зоны
  `_lastKneeDeg >= _minExtensionDeg` → `_lastKneeDeg >= _minExtensionDeg &&
  _smoothedLift >= _cycle.LiftedAt`. Больше ничего не меняется (cues, счёт,
  статы, каталог — как есть).

Проверка на записи 07:41: **4 зачёта / 3 отказа** — три медленных удара и
взмах на высоту чудан проходят (есть выпрямленные кадры на верхушке), три
подъёма колена отклоняются («Выпрями ногу»: прямые кадры у них только на
опускании, подъём 0.75–0.93 < 1.0). Совпадает с граунд-трусом. Порог 0.9
вместо 1.0 пропустил бы подъём колена с кадром на 0.93 — не ослаблять.

## Тесты

- Существующие тесты yoko не меняются: во всех зонных билдерах подъём ≥ 1.25 в
  момент сэмплирования (α = 1), гейт проходится.
- Новый юнит-тест `ExtensionOnlyOnDescentDoesNotAward`: Floor →
  `ChamberHigh` (вход в цикл с согнутым коленом) → `Kick(0.78)` (нога прямая,
  но подъём 0.6 — опускание) → Floor: Reps 0, NoReps 1, cue «Выпрями ногу».
  На текущем коде тест красный (опускание даёт гэдан), на новом — зелёный.
- Корпус: `yoko_gedan_session.csv` (= `pose_rec_074125.csv`) через
  `YokoGeriAnalyzer(KickZone.Gedan)` → **Reps 4, NoReps 3, BestZone Chudan**.
  Корпусы пуш-апа (5/4/0), приседа (18/15/1), wall-sit (6/0) не трогаются.

## Верификация

EditMode зелёные → `unity build` → `adb install` → живая проверка: гэдан-удар
с выпрямлением считается; подъём колена и опускание без удара — «Выпрями ногу».

## Вне области

- Требование замаха («Сначала колено») — по-прежнему не проверяем.
- Сессия 07:18 (0 циклов, содержимое неизвестно) — корпус по ней не строим.
