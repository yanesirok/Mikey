# Wall-sit v2: маржа таза вместо 3D-углов + только у стены

**Дата:** 2026-08-05
**Статус:** одобрено к реализации (дизайн)
**Дополняет:** `2026-08-05-squat-hipdrop-signal-design.md`
**Тема:** wall-sit не засчитывает правильную посадку у стены (эталон — видео
youtube.com/shorts/mDdLC-yKudY) и при этом считает сидение на полу. Причина —
сигнал: 3D-углы колена/бедра ломаются на шумной глубине z.

## Улики (сессия 03:12, граунд-трус: несколько подходов по 5–10 с)

- 3D-угол колена во время реального сидения скачет 65°→135° кадр к кадру и
  вылетает из окна 70–120°; удержание рвётся, лучший кусок — 7 с.
- Правильная глубокая посадка у стены читалась как 52–66° («слишком глубоко»)
  и вообще не считалась — главная жалоба пользователя.
- Сидение НА ПОЛУ (таз на целую голень ниже колен) засчитано как 2 с
  удержания; переходы «встаю/сажусь» тоже ловились окном углов.
- Маржа таза (сигнал приседа v2) на тех же кадрах стабильна: удержания читаются
  целиком — 3.5 / 2.7 / 6.9 / 6.2 / 4.2 с (совпадает с граунд-трусом), пол
  (24 кадра) и переходы отсечены. Ходьба (`walking_noise.csv`) — 0 с;
  сессия приседаний (03:05) — максимум ~1 с шума.

## Сигнал

Per-leg маржа `(knee.Y − hip.Y) / |ankle.Y − knee.Y|` (та же, что в
`SquatAnalyzer`), сигнал = **max по пригодным ногам**. «В позе» = сигнал в окне
**[−0.45 … +0.5]**:

- сидит у стены (таз около уровня коленей) → в окне, секунды идут;
- стоит/привстал (~1.0) → выше окна, cue «Ниже»;
- сидит на полу (таз глубоко под коленями, < −0.45) → ниже окна, cue «Выше» —
  упражнение выполняется только у стены, пол не считается;
- глубина z не используется — анфас работает наравне с профилем.

Прокси «стены»: наклон торса от вертикали ≤ **40°** (спина у стены вертикальна).
Плечо берётся со стороны более видимой ноги и только если само видимо ≥ 0.5;
невидимое плечо проверку пропускает (не блокирует). Наклон > 40° в окне сидения →
`BadForm`, cue «Спиной к стене», таймер стоит. На записи 03:12 порог 40° не
отверг ни одного кадра.

## Фикс

- **`PoseMath`**: добавить `HipDropMargin(PoseLandmark hip, PoseLandmark knee,
  PoseLandmark ankle)` (NaN при голени < 1e-4); `SquatAnalyzer.Margin`
  делегирует ему — формула живёт в одном месте.
- **`WallSitAnalyzer`**: конструктор `WallSitAnalyzer(HoldTimer timer = null,
  float minVisibility = 0.5f, float seatLowAt = -0.45f, float seatHighAt = 0.5f,
  float maxTorsoLeanDeg = 40f)` — параметры углов уходят. Видимость по-ножно
  (hip/knee/ankle ≥ 0.5, зеркально приседу); нет пригодных ног → `NotVisible`,
  cue «В кадр» (совет «боком» больше не нужен), таймер не обновляется —
  короткие моргания сшивает грейс `HoldTimer` (1.0 с), как сейчас.
- Cue-приоритет: NotVisible «В кадр» → выше окна «Ниже» → ниже окна «Выше» →
  наклон «Спиной к стене» → GoodForm (пусто). `DebugInfo`: сигнал, маржи ног,
  наклон, hold/best, vis.
- **Не меняется**: `HoldTimer`, `Reps = (int)BestSeconds` (лучшее непрерывное
  удержание — стандарт wall-sit-теста; 120 с = 100 баллов выносливости),
  `Level0Results`, `StatCalculator`, каталог.
- **Песочница** (`ExerciseSandbox.DrawLive`): для упражнения с Id `wallsit`
  показать строку «Спиной к стене, бёдра параллельно полу».

## Тесты

- Существующие 6 `WallSitAnalyzerTests` переживают смену сигнала на текущем
  билдере (маржа зависит только от высоты таза: 90° → 0.00 «в позе»,
  150° → +1.08 «Ниже», 55° → −0.72 «Выше»); ассерты не меняются.
- Новые юнит-тесты: `FloorSitDoesNotAccumulate` (55°-кадры 5 с → Reps 0 — пол
  не считается) и `HeavyLeanPausesTimerWithWallCue` (`WallSit(90, 140)` → наклон
  ≈50° → `BadForm`, «Спиной к стене», секунды не идут).
- Корпус: новый `wallsit_session.csv` (= `pose_rec_031226.csv`) → **Reps = 6**
  (лучшее удержание 6.2 с по эталонному реплею); `walking_noise.csv` через
  `WallSitAnalyzer` → **0**. Корпусы пуш-апа (5/4/0) и приседа (18/15/1)
  не трогаются.

## Верификация

EditMode зелёные → `unity build` → `adb install` → живая проверка: посадка у
стены как в видео — секунды идут непрерывно; встал — пауза; сел на пол — не
считается.
