# Yoko geri по трём высотам: гэдан / чудан / дзёдан

**Дата:** 2026-08-06
**Статус:** одобрено к реализации (дизайн)
**Тема:** вместо одного «Yoko-geri slow» (медленный подъём без высоты) — три отдельных
упражнения по высоте удара, как у mae geri. Это проверка боковой растяжки.
Эталон: фото пользователя `yoko_geri_photos/` (удержания у столба на трёх высотах
плюс кадр замаха) и видео youtu.be/iodw1dHq-ag.

## Решения пользователя

- Три варианта выполняются по отдельности (три записи в пикере), не одним экраном.
- Зачёт: любой темп, главное высота (вариант «медленно + высота» и «на время» отклонены).
- Гибкость в статах = среднее из лучших зон mae geri и yoko geri — один вид удара
  больше не даёт 100.

## Сигнал

Всё переиспользуется из mae geri, ничего нового в геометрии:

- Подъём стопы: `(supportAnkle.Y − kickAnkle.Y) / supportShank`, бьющая нога — та,
  что выше; сглаживание α = 0.6; цикл `LegLiftCycle` (liftedAt 1.0, groundedAt 0.25,
  minLiftSeconds 0.2).
- Высота: `KickHeightZone.Classify(ankle.Y, hip.Y, shoulder.Y)` — якоря от
  собственного тела в том же кадре (стопа ниже таза = гэдан, таз…плечо = чудан,
  выше плеча = дзёдан), калибровка не нужна.
- Стоять лицом к камере (боком высоту бокового удара не видно): cue NotVisible —
  «В кадр (лицом)». Видимость как у mae geri: обе ноги (таз/колено/лодыжка) и оба
  плеча ≥ 0.6.
- Опора рукой о стену/столб разрешена и не проверяется.

## Зачёт: удар, а не подъём колена

Урок кадра замаха (колено у груди — стопа уже «в зоне», удара нет): зона
засчитывается только в кадрах, где нога **выпрямлена** — 2D-угол колена
таз–колено–лодыжка (`PoseMath.AngleDeg`, плоскость кадра — глубина z с её шумом
не участвует) ≥ **150°**. За цикл подъёма копится пик зоны по выпрямленным кадрам:

- пик ≥ заданной зоны → **Reps++** (выше заданной — тоже зачёт, политика уровня 0);
  `TotalLiftedSeconds += LiftedSeconds` (время в воздухе, для баланса);
- пик ниже заданной → **NoReps++**, cue «Выше»;
- ни одного выпрямленного кадра за цикл → **NoReps++**, cue «Выпрями ногу»;
- `BestZone` — лучшая зона за сет независимо от заданной (для гибкости),
  зеркально mae geri.

Проверка замаха («Сначала колено») сознательно не делается: уровень 0 проверяет
растяжку и навык, а не учит технике.

## Фикс

- **`YokoGeriAnalyzer`**: конструктор `YokoGeriAnalyzer(KickZone requested,
  LegLiftCycle cycle = null, float minVisibility = 0.6f,
  float minExtensionDeg = 150f, float smoothingAlpha = 0.6f)`;
  `slowMinSeconds` уходит. `Id = "yokogeri-" + зона`, `DisplayName = "Yoko geri " +
  зона` (в нижнем регистре, как mae geri). Свойства `Reps`, `NoReps`,
  `TotalLiftedSeconds`, `BestZone`, `Cue`, `FormState`, `DebugInfo` (сигнал, фаза,
  пик, угол колена, vis).
- **`ExerciseCatalog`**: `yokogeri-slow` удаляется; добавляются
  `yokogeri-gedan` «Yoko geri gedan», `yokogeri-chudan` «Yoko geri chudan»,
  `yokogeri-jodan` «Yoko geri jodan» — рядом с mae geri.
- **`Level0Results`**: новое поле `YokoGeriBestZone` (int, как `MaeGeriBestZone`).
  Существующие поля `YokoGeriSlowReps` и `YokoGeriHoldSeconds` **не переименовывать**
  (JsonUtility — переименование потеряло бы сохранённые результаты): смысл теперь
  «лучшее число повторов за сет любого варианта yoko» и «лучшее суммарное время в
  воздухе за сет»; max-merge как раньше.
- **`StatCalculator`**: гибкость = округлённое среднее
  `(FlexibilityByZone[mae] + FlexibilityByZone[yoko]) / 2`. Баланс не меняется
  (повторы yoko → 70 %, время в воздухе → 30 %).
- **Песочница** (`ExerciseSandbox.DrawLive`): для Id с префиксом `yokogeri` —
  строка «Лицом к камере, можно держаться за стену» (рядом с подсказкой wall-sit).

## Тесты

- `YokoGeriAnalyzerTests` переписываются под зоны (билдер `LegTestFrames.Kick`
  уже даёт прямую ногу с зонами gedan 0.65 / chudan 0.35 / jodan 0.18):
  удар в заданную зону считается (быстрый — тоже); выше заданной — считается;
  ниже — NoRep «Выше»; высокий замах без выпрямления (согнутое колено, стопа
  поднята) — NoRep «Выпрями ногу»; NotVisible-cue; `BestZone` копится независимо
  от заданной; `TotalLiftedSeconds` копится по зачтённым повторам; каталог отдаёт
  три id, `yokogeri-slow` — null.
- `StatCalculatorTests`: якоря на 100 теперь требуют `YokoGeriBestZone = Jodan`;
  только mae jodan → гибкость 50; Absorb от yoko-варианта обновляет
  `YokoGeriBestZone`/`YokoGeriSlowReps`/`YokoGeriHoldSeconds`.
- Корпусных записей yoko geri нет — появятся из смоука на телефоне; корпус-тест
  добавится по его итогам (как было с приседом и wall-sit).

## Верификация

EditMode зелёные → `unity build` → `adb install` → живая проверка по фото:
пенок вниз / в середину / в горло у стены — каждый вариант считает свою высоту,
удар выше заданной тоже идёт в зачёт, подъём колена без выпрямления не считается.

## Вне области

- Проверка замаха и «точный» режим обучения технике.
- Перевод mae geri на 2D-угол выпрямления (сейчас у него 3D-угол колена только
  для подсказки «Сначала колено» — не мешает счёту).
- Корпус-тесты yoko (после смоука).
