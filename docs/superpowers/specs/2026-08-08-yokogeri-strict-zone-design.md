# Yoko geri v5: строгое окно высоты

**Дата:** 2026-08-08
**Статус:** одобрено к реализации (дизайн)
**Дополняет:** `2026-08-08-yokogeri-chamber-required-design.md` (замах и сигнатура остаются)
**Тема:** в режиме гэдан засчитываются удары выше дозволенной высоты — мягкая
политика «заданная зона или выше» (из первого дизайна yoko-зон) отменяется.

## Улики (сессия 03:28 на v4, граунд-трус подтверждён)

- 9 движений: 4 чистых гэдана (стопа у колена опорной, полоса 0.5–1.2) и 2
  высоких удара на дзёдан-высоту (стопа выше таза, fast-кадры r≈3.4) — оба
  засчитаны из-за «выше — тоже зачёт». Пользователь: не должны.
- Один из высоких ударов содержит и гэдан-кадры (транзит по пути вверх) —
  классификация по максимуму зон цикла обязана отдать его дзёдану.

## Правило (v5)

Зона цикла = максимум зон по зачётным кадрам (замах → выпрямление → fast/band,
как в v4 — ничего в накоплении не меняется). Повтор засчитывается **только при
точном совпадении**: `peak == requested` (было `>=`).

Подсказки на отказе (по убыванию приоритета):

1. замаха не было → «Сначала колено»;
2. пик пуст → «Выпрями ногу»;
3. пик выше заданной → **«Ниже»** (новая строка для yoko);
4. пик ниже заданной → «Выше».

- Для чудана/дзёдана строгое окно даёт обе границы само: гэдан-удар в режиме
  чудан → «Выше», дзёдан-удар → «Ниже».
- Нижний порог «слишком низкого» гэдана НЕ вводится: настоящие удары
  пользователя в полосе опускаются до 0.46–0.50 голени — любой отсекающий
  порог режет и их (проверено на размеченной сессии). Появится живой случай —
  отделим по записи.
- `BestZone` по-прежнему обновляется вычисленным пиком даже на «Ниже»-отказе:
  дзёдан-удар в гэдан-режиме демонстрирует растяжку, гибкость капает.
- Mae geri не трогаем (там «выше — зачёт» пока остаётся; отдельное решение).

## Тесты

- Юнит `KickAboveRequestedZoneCounts` переворачивается в
  `KickAboveRequestedZoneIsNoRepWithLowerCue`: замах + дзёдан-удар в режиме
  гэдан → Reps 0, NoReps 1, cue «Ниже», BestZone Jodan (гибкость копится).
  Остальные юниты не меняются (в т.ч. «ниже заданной → „Выше“»).
- Корпуса: `yoko_gedan_session.csv` (07:41) перезакрепляется **4/3/Chudan →
  3/4/Chudan** (чудан-мах теперь «Ниже» — прямое следствие строгого окна);
  `yoko_gedan_mixed.csv` — **5/9/Gedan без изменений** (все зачёты и так
  гэдан); новый `yoko_gedan_heights.csv` (= `pose_rec_032811.csv`) →
  **Reps 4, NoReps 5, BestZone Jodan**; `walking_noise.csv` → 0 без изменений.
  Красная фаза на текущем коде: ровно три падения — GedanSession (4≠3),
  новый Heights (6≠4), перевёрнутый юнит (1≠0).
- Корпусы пуш-апа (5/4/0), приседа (18/15/1), wall-sit (6/0) не трогаются.

## Верификация

EditMode зелёные → `unity build` → `adb install` → живая проверка в режиме
гэдан: удар на высоте колена — зачёт; тот же удар в корпус/голову — «Ниже»;
в режимах чудан/дзёдан — зеркально.
