# Бой: гибридная 2.5D-арена (Ghost of Tsushima) + блок

**Дата:** 2026-07-11
**Статус:** одобрено (выбор пользователя: гибрид 2.5D; кнопки — рука/нога/блок; все визуальные ассеты — Higgsfield)

## Проблемы, которые чинит этот срез

1. Бойцы проваливаются в пол — пивот модели в центре тела, спавн по y=0.
2. Анимации не проигрываются — Setup запускался до завершения импорта FBX; `Clip()` возвращал null, состояния без motion (bind pose).
3. Голые базовые тела — читаются как манекены.
4. Фон — плоская картинка без глубины.

## Решения

### Бойцы
- Спавн выравнивает низ объединённых bounds всех рендереров на y=0.
- `FightSceneSetup.Setup()` прерывается с ошибкой, если любой требуемый клип не найден — никаких полусобранных сцен.
- Тела тонируются в «тканевые» цвета: игрок — индиго, противник — тёмно-багровый. Настоящие кимоно-модели — отдельный этап (вне рамок).

### Арена (гибрид 2.5D, как в Shadow Fight)
- Дальний план: перегенерированный задник (Higgsfield) — только небо/горы/дальнее поле, unlit quad.
- Средний/ближний план — настоящее 3D из сгенерированных Higgsfield моделей (image → generate_3d → GLB, импорт через glTFast):
  - тории справа, красный клён слева, ряды кустов пампасной травы на z ≈ 2.5–6.
- `GrassSway` — покачивание травы синусом (transform-based, дёшево для мобилки).
- Уже есть и остаются: частицы листьев/угольков, тёплый туман, золотое солнце.
- Параллакс возникает сам из глубины слоёв (камера пока статична — камера-слежение вне рамок).

### Управление и блок
- Кнопки: рука, нога, **блок** (сгенерированы Higgsfield, единый стиль).
- Блок: удержание кнопки (S на клавиатуре) → бой стойка `Blocking` (UAL2, CC0); входящий урон × `FightRules.BlockDamageMultiplier` (0.2), без оглушения, реакция `Block_Hit`; в блоке нельзя ходить и бить.
- Анимации блока — из UAL2_Standard.fbx (Humanoid, как UAL1).

### Тесты
- `FightRulesTests`: блок-множитель (урон сквозь блок меньше обычного, округление).

## Вне рамок
- Настоящие удары ногами (Mixamo, ждёт пользователя) — kick пока играет Punch_Cross.
- Кимоно-персонажи, камера-слежение, полоски HP, спецприёмы/дальний бой.
