# Бой: гибридная 2.5D-арена (Ghost of Tsushima) + блок

**Дата:** 2026-07-11
**Статус:** одобрено (выбор пользователя: гибрид 2.5D; кнопки — рука/нога/блок; все визуальные ассеты — Higgsfield)

## Проблемы, которые чинит этот срез

1. Бойцы проваливаются в пол — пивот модели в центре тела, спавн по y=0.
2. Анимации не проигрываются — Setup запускался до завершения импорта FBX; `Clip()` возвращал null, состояния без motion (bind pose).
3. Голые базовые тела — читаются как манекены.
4. Фон — плоская картинка без глубины.

## Решения

### Бойцы
- Спавн выравнивает низ объединённых bounds всех рендереров на y=0.
- `FightSceneSetup.Setup()` прерывается с ошибкой, если любой требуемый клип не найден — никаких полусобранных сцен.
- Тела тонируются в «тканевые» цвета: игрок — индиго, противник — тёмно-багровый. Настоящие кимоно-модели — отдельный этап (вне рамок).

### Арена (полное 3D — обновлено по требованию пользователя 2026-07-11)
Фото-задник исключён полностью; никаких картинок в мире.
- **Небо** — процедурный скайбокс (Skybox/Procedural) в закатных тонах, солнце = сценовый Directional Light (`RenderSettings.sun`).
- **Земля** — Unity Terrain 200×200 м из кода: плоское боевое плато в центре, Перлин-холмы дальше, горное кольцо по горизонту; один золотой terrain layer.
- **Дымка** — линейный сине-серый туман 25–130 м: ближнее поле золотое, хребты тают в GoT-дымке.
- **3D-объекты** (Higgsfield GLB через glTFast): тории, 3 красных клёна, ~54 куста пампасной травы (нормализация высоты по bounds, детерминированный рассев, покачивание `GrassSway`). Заземление всех объектов — по высоте террейна.
- Частицы листьев/угольков остаются.
- Камера статична (слежение — следующий этап).

### Управление и блок
- Кнопки: рука, нога, **блок** (сгенерированы Higgsfield, единый стиль).
- Блок: удержание кнопки (S на клавиатуре) → стойка `Idle_Shield_Loop` (UAL2, CC0 — безоружного блока в бесплатной версии нет, щитовая стойка читается как защита); входящий урон × `FightRules.BlockDamageMultiplier` (0.2), без оглушения, реакция `Sword_Block` (парирование); в блоке нельзя ходить и бить.
- Анимации блока — из UAL2_Standard.fbx (Humanoid, как UAL1).

### Тесты
- `FightRulesTests`: блок-множитель (урон сквозь блок меньше обычного, округление).

## Вне рамок
- Настоящие удары ногами (Mixamo, ждёт пользователя) — kick пока играет Punch_Cross.
- Кимоно-персонажи, камера-слежение, полоски HP, спецприёмы/дальний бой.
