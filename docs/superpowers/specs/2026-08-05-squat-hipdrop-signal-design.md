# Присед v2: сигнал «таз над коленями» вместо угла колена

**Дата:** 2026-08-05
**Статус:** одобрено к реализации (дизайн)
**Дополняет:** `2026-08-05-squat-recall-no-voice-design.md`
**Тема:** после лечения сглаживания присед всё ещё пропускает повторы сбоку, почти
не видит анфас и иногда считает ходьбу. Причина — сам сигнал: угол колена ломается
на шумной глубине (анфас) и срабатывает на махе одной ноги (ходьба).

## Улики (свежая сессия 02:07 + корпусные записи)

- Новая сессия (~8–10 сбоку + 3–4 анфас): текущий сигнал — 9 (боковые), новый — 15,
  ритмичный таймлайн каждые 4–6 с, анфас ловится.
- Ходьба (запись «хожу/делаю другое»): текущий сигнал даёт фантом (мах ноги сгибает
  колено); новый — опорная нога всегда прямая, остаётся 1 спорный случай (опускание
  на пол — обе ноги реально согнуты; для щедрого уровня 0 приемлемо).
- Старая склейка сессий: 16 → 18.
- Дистанции порогов от шума велики: стоя медиана сигнала 0.98–1.06, низ уходит < 0.

## Сигнал

Для каждой ноги: `margin = (knee.Y − hip.Y) / |ankle.Y − knee.Y|` — насколько таз
выше колена в долях длины голени (image-space, Y вниз). Стоя ≈ 1.0, параллель ≈ 0,
глубже — отрицательно. **Сигнал приседа = max по пригодным ногам** («самая стоячая»
нога): проваливается, только когда сгибаются ОБЕ ноги — ходьба с прямой опорной
ногой не проходит. Глубина z не используется — анфас работает наравне с профилем.

## Фикс (`SquatAnalyzer`)

- Конструктор: `SquatAnalyzer(RepCounter counter = null, float minVisibility = 0.5f,
  float maxTorsoLeanDeg = 50f, float smoothingAlpha = 1f, float standAt = 0.7f,
  float deepAt = 0.45f)`; дефолтный счётчик
  `new RepCounter(upThresholdDeg: standAt, downThresholdDeg: deepAt,
  minRepSeconds: 0.3, downDebounceFrames: 2)` — счётчик уже безразмерный по сути,
  его докстрока обобщается («скалярный сигнал: угол или нормированная высота»),
  имена параметров не трогаем.
- Видимость — **по-ножно**: нога пригодна при min(vis(hip,knee,ankle)) ≥ 0.5; нет
  ни одной пригодной ноги → `NotVisible` (cue становится просто «В кадр» — совет
  «боком» больше не нужен, анфас поддержан), `ResetDownStreak()`.
- Проверка наклона корпуса (метка `NoReps`, «Спину прямее») остаётся; плечо берётся
  со стороны более видимой ноги и только если оно само видимо ≥ 0.5.
- `DebugInfo`: сигнал, фаза, маржи обеих ног, видимость.

## Тесты

- Существующие `SquatAnalyzerTests` переживают смену сигнала на текущей геометрии
  билдера (проверено расчётом: 175° → margin ≈ 1.24 «стоя»; 95° → 0.11 «глубоко»;
  120° → 0.63 — межзонье, недосед не считается).
- Новый юнит-тест `WalkingStrideDoesNotCount`: кадры «одна нога согнута, опорная
  прямая» (новый билдер асимметричных ног в `LegTestFrames`) → 0 повторов — это
  главное анти-фантомное свойство сигнала.
- Корпус: `squats_mixed_sessions.csv` → **18** (было 16);
  новый `squats_side_and_front.csv` (= `pose_rec_020718.csv`) → **15**
  (сбоку + анфас, характеризация при граунд-трусе «~12–14»);
  `walking_noise.csv` через `SquatAnalyzer` → **1** (документированный спорный
  случай: опускание на пол сгибает обе ноги; щедрый уровень 0 это терпит).
