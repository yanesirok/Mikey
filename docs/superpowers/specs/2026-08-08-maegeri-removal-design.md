# Удаление mae geri

**Дата:** 2026-08-08
**Статус:** одобрено к реализации (дизайн)
**Тема:** пользователь: удары mae geri не нужны — убрать все три упражнения
(гэдан/чудан/дзёдан) из приложения. Полное удаление кода, не скрытие кнопок
(git хранит историю — вернуть можно всегда).

## Изменения

- **Каталог** (`ExerciseCatalog.cs`): удалить три строки `maegeri-*` —
  остаётся 6 упражнений; сетка пикера (3 в ряд) сама станет 2 ряда по 3,
  правок в сандбоксе не нужно.
- **Анализатор**: удалить `Assets/Pose/MaeGeriAnalyzer.cs` и
  `Assets/Pose/Tests/MaeGeriAnalyzerTests.cs` (8 тестов) вместе с `.meta`.
- **Сейвы** (`Level0Results.cs`): удалить поле `MaeGeriBestZone` и ветку
  `case MaeGeriAnalyzer` в `Absorb`. Старые сейвы совместимы: `JsonUtility`
  молча игнорирует лишнее JSON-поле.
- **Гибкость** (`StatCalculator.cs`): было среднее mae + yoko (каждый удар —
  максимум 50), становится только по yoko:
  `flexibility = FlexibilityByZone[ClampZone(r.YokoGeriBestZone)]`.
  Следствие: дзёдан yoko даёт 100. Комментарий про «два вида растяжки»
  убрать. Баланс и остальные статы не меняются.
- **Тесты статов** (`StatCalculatorTests.cs`): убрать `MaeGeriBestZone` из
  якорей и середин (ассерты не меняются — среднее двух равных зон равно
  одной); `FlexibilityAveragesFrontAndSideKicks` переработать в
  `FlexibilityComesFromSideKick` (пустые результаты → 0, yoko дзёдан → 100);
  из Absorb-теста убрать mae-секцию.

## Не трогаем

- `Assets/Fight/animations` — мокап-анимации mae geri для файт-сцены
  (параллельная работа, к детекции упражнений отношения не имеет).
- Yoko geri (v5), корпусные записи, пуш-ап/присед/wall-sit.

## Верификация

EditMode зелёные (ориентир 88 тестов: 96 − 8 удалённых) → `unity build` →
`adb install` → живая проверка: в пикере 6 кнопок, mae geri нет; yoko geri
работает как раньше.
