# Приседания: щедрый зачёт + без голоса на уровне 0

**Дата:** 2026-08-05
**Статус:** одобрено к реализации (дизайн)
**Тема:** приседания теряют повторы (пользователь: 8 сделано, 3 засчитано сбоку,
0 анфас); голосовые подсказки на уровне 0 не нужны (проверяем, не учим).

## Улики (три записи с устройства, 2026-08-05 01:09–01:27)

- У `SquatAnalyzer` остались настройки, которые уже уличены в воровстве повторов у
  пуш-апа: EMA α=0.6 без дебаунса. Реплей записей: лечение пуш-апа (α=1, дебаунс 2)
  поднимает счёт 11→16, 7→9, 0→1 по трём файлам.
- **Пороги глубины не виноваты**: нижние точки пользователя — 74–99° по колену,
  глубже порога 100°; ослабление порога до 110° не добавляет ни одного повтора.
  160°/100° остаются.
- **Анфас — слабый ракурс** для приседаний (колено меряется через шумную глубину z):
  даже щедрая конфигурация находит 1–2. Уровень 0 остаётся «телефон сбоку»
  (подсказка уже на экране выбора); поддержка анфаса — вне области.
- Побочно: **буфер записи не чистится между упражнениями** — CSV склеивают сессии,
  что мешает точному граунд-трусу (склейка не позволила вычленить контрольные «8»).

## Фикс

1. **`SquatAnalyzer`** (зеркально пуш-апу): дефолт `smoothingAlpha` 0.6 → **1.0**;
   дефолтный счётчик → `new RepCounter(upThresholdDeg: 160f, downThresholdDeg: 100f,
   minRepSeconds: 0.3, downDebounceFrames: 2)`; на невалидных кадрах (низкая
   видимость) вызывается `_counter.ResetDownStreak()`. Докстроки — про дебаунс
   вместо EMA. Пороги углов и наклона корпуса не меняются.
2. **Голос долой из песочницы**: из `ExerciseSandbox` удаляются поле `_voice`, его
   создание/Dispose и весь блок озвучки cue в `Update()` (вместе с полями троттлинга
   `_lastSpokenCue`/`_lastSpeakTime`/`MinSpeakInterval`). Класс `AndroidVoice`
   остаётся в проекте — пригодится «точному» режиму обучения.
3. **Очистка буфера записи**: `PoseController.SelectExercise` добавляет
   `_recording.Clear();` — каждый CSV становится одной сессией одного упражнения.
