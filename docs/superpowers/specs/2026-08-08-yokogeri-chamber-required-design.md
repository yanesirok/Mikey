# Yoko geri v4: обязательный замах перед выпрямлением

**Дата:** 2026-08-08
**Статус:** одобрено к реализации (дизайн)
**Дополняет:** `2026-08-08-yokogeri-kick-signature-design.md` (правила v3 остаются, поверх них — замах)
**Тема:** пользователь требует: перед каждым ударом — замах (колено поднято
согнутым, эталон — фото `issues/Screenshot_20260724-203949_Gallery.jpg`); удар
без замаха не должен считаться. Отменяет решение v2 «замах не проверяем».

## Улики (реплей v4-правила по корпусам)

- Размеченная сессия 07:41: **4/3 без изменений** — у всех настоящих ударов и
  у чудан-маха замах был (мин. угол колена в цикле 0–6°).
- Смешанная сессия 01:53: 7/7 → **5/9** — вылетают ровно два маха прямой ногой
  без замаха (мин. колено 114° и 133°), остальные зачёты нетронуты.
- Ходьба: 0 зачётов, без изменений.

## Правило (v4)

Внутри цикла подъёма зона копится (быстрый и медленный пути v3 без изменений)
**только после** кадра с согнутым коленом: 2D-угол таз–колено–лодыжка ≤
**110°** (`chamberMaxKneeDeg`, тот же номинал, что у mae geri) в фазе Lifted.
Выпрямление до замаха в зачёт не идёт — порядок обязателен.

Подсказки на завершении цикла (пик ниже заданной зоны):

1. замаха не было → **«Сначала колено»** (первопричина, строка mae geri);
2. замах был, пик пуст (нет выпрямления на высоте) → «Выпрями ногу»;
3. пик есть, но ниже заданной → «Выше».

`BestZone` обновляется вычисленным пиком цикла, как раньше (в том числе на
«Выше»-отказе); у маха без замаха пик пуст — гибкость не растёт. Остальное — `Reps`/`NoReps`/`TotalLiftedSeconds`/статы/каталог
— без изменений. Требование действует во всех трёх вариантах (гэдан/чудан/
дзёдан — общий анализатор). Mae geri не трогаем (у него «Сначала колено» —
мягкое предупреждение; ужесточение — отдельным решением после его смоука).

## Фикс

`YokoGeriAnalyzer`: параметр `float chamberMaxKneeDeg = 110f` (в конец списка
параметров конструктора); поле `_chambered` (сброс на входе в цикл); в Lifted
после вычисления `_lastKneeDeg`: `if (_lastKneeDeg <= _chamberMaxKneeDeg)
_chambered = true;` зонные ветки (fast/band) выполняются только при
`_chambered`; на завершении cue-приоритет из «Правила». `DebugInfo` — добавить
флаг замаха.

## Тесты

- Существующие зонные юнит-тесты получают кадр `ChamberHigh` перед кадром
  удара (по новому правилу удар без замаха и не должен считаться) — ассерты
  чисел не меняются. `SlowLowKickCountsThroughBand`,
  `ExtensionOnlyOnDescentDoesNotAward`, `HighChamberWithoutExtension…`
  уже начинаются с `ChamberHigh` — не меняются (их cue остаются как есть).
- Новый юнит-тест `StraightSwingWithoutChamberIsNoRep`: Floor → `Kick(JodanY)`
  (прямая нога сразу, замаха нет) → Floor: Reps 0, NoReps 1, cue
  «Сначала колено», BestZone None. На текущем коде красный (быстрый путь
  засчитывает дзёдан).
- Корпуса: `yoko_gedan_session.csv` — ассерты **не меняются** (4/3/Chudan);
  `yoko_gedan_mixed.csv` — перезакрепляется **7/7/Chudan → 5/9/Gedan**
  (красная фаза на текущем коде); `walking_noise.csv` → 0 (зелёный в обеих
  фазах). Корпусы пуш-апа (5/4/0), приседа (18/15/1), wall-sit (6/0) не
  трогаются.

## Верификация

EditMode зелёные → `unity build` → `adb install` → живая проверка: удар с
замахом (как на фото) считается; мах прямой ногой — «Сначала колено»; подъём
колена без выпрямления — «Выпрями ногу»; опускание — не считается.

## Вне области

- Ужесточение замаха в mae geri.
- Различение бокового и фронтального движения (по-прежнему отдельный цикл,
  если понадобится).
