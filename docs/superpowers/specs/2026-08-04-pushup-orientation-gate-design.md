# Гейт горизонтальности пуш-апа: фантомные повторы стоя

**Дата:** 2026-08-04
**Статус:** одобрено к реализации (дизайн)
**Тема:** багфикс — отжимания засчитываются, когда игрок стоит, ходит или делает
произвольные движения перед камерой.

## Корневая причина

Гейт «в позиции упора лёжа» в `PushUpFormEvaluator` проверяет видимость точек и
прямизну линии плечо–таз–лодыжка (3D-угол ≥ 135°). Угол сознательно сделан
инвариантным к ориентации (независимость от положения камеры), поэтому у стоящего
человека линия тела тоже «прямая» — гейт пропускает. Дальше счётчик слушает угол
локтя, а при ходьбе/жестикуляции локоть пересекает пороги 105°/140° → фантомные
повторы. Не хватает единственной проверки: корпус должен быть **горизонтален**.

Остальные техники уровня 0 (приседания, wall-sit, удары) выполняются стоя — у них
этой дыры нет по построению.

## Фикс

`PushUpFormEvaluator`:

- новый параметр конструктора `maxTorsoTiltDeg = 40f`;
- после гейта видимости — наклон вектора плечо→лодыжка (лучше видимой стороны)
  к горизонтали кадра по 2D-нормализованным координатам:
  `tiltDeg = atan2(|ankle.Y - shoulder.Y|, |ankle.X - shoulder.X|)`;
- `tiltDeg > maxTorsoTiltDeg` → существующий фолт `NotInPosition`
  («Прими упор лёжа»). Новых enum-значений, cue и правок HUD нет.

`PushUpAnalyzer` не меняется: при `NotInPosition` счёт уже на паузе и
EMA-база сбрасывается.

Порог грубый сознательно: он отличает «лежит» (~0–20°) от «стоит/идёт» (~70–90°),
поэтому искажение нормализованных координат из-за соотношения сторон кадра
несущественно.

## Тесты

- `PoseTestFrames` получает билдер вертикального (стоящего) скелета с управляемым
  углом локтя.
- Оценщик: стоящий скелет → `NotInPosition`.
- Анализатор: поток стоящих кадров с осциллирующим углом локтя → 0 повторов.
- Все существующие тесты (горизонтальная раскладка) проходят без правок.

## Верификация

EditMode-тесты зелёные → инкрементальная пересборка APK → переустановка на
телефон → повторить смоук: ходьба и произвольные движения перед камерой не
двигают счёт; настоящие отжимания сбоку считаются как раньше.

## Вне области

- Аналогичные ложные срабатывания других техник, если их покажет смоук, — отдельно
  по факту (у стоячих техник ортогональная природа поз).
- Перекалибровка порогов 105°/140° — не требуется, фикс их не касается.
