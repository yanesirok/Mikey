Политика конфиденциальности Mikey

Редакция от 22 августа 2026 года

Mikey — приложение для тренировок по карате. Оно считает повторения упражнений по изображению с камеры телефона и сохраняет результаты. Этот документ объясняет, какие данные приложение собирает, что с ними происходит и как их удалить.

Главное в двух строках. Изображение с камеры никогда не покидает ваш телефон — распознавание позы целиком происходит на устройстве. Вход в аккаунт необязателен: без него приложение работает полностью, а данные не уходят никуда.

1. Что происходит без входа в аккаунт

Если вы не входите через Google, приложение не передаёт о вас никаких данных. Профиль, результаты тренировок и прогресс хранятся только в памяти самого приложения на вашем телефоне и исчезают вместе с ним при удалении приложения.

2. Что собирается после входа в аккаунт

Вход нужен ровно для одного: чтобы прогресс вернулся после переустановки приложения или при смене телефона. После входа на сервер отправляется следующее.

3. Что не собирается никогда

  • Изображение с камеры. Кадры обрабатываются прямо на телефоне и не отправляются ни на какой сервер. Ни снимков, ни видео не сохраняется.
  • Координаты вашего скелета. Приложение умеет записывать их в файл для отладки — этот файл остаётся на устройстве и никуда не передаётся.
  • Местоположение, список контактов, содержимое телефона. Приложение их не запрашивает.
  • Настройки громкости и прочие настройки устройства.

4. Разрешение на камеру

Приложение просит доступ к камере только перед началом упражнения и использует её исключительно для подсчёта повторений в реальном времени. Отказ в доступе не мешает пользоваться остальной частью приложения.

5. Где хранятся данные

Данные хранятся в базе данных сервиса Supabase, расположенной в дата-центре во Франкфурте (Германия, Европейский союз). Доступ к своей записи есть только у вас: он выдаётся по токену, который выпускает Google при входе, и правила базы данных не позволяют одному пользователю прочитать или изменить запись другого.

6. Сколько данные хранятся

Пока вы пользуетесь аккаунтом. Удаление — по вашей команде, немедленно и необратимо (см. раздел 8).

7. Кому данные передаются

Никому. Данные не продаются, не передаются рекламодателям и не используются для рекламы. В обработке участвуют только два поставщика услуг, без которых приложение не работает: Google — для входа в аккаунт, и Supabase — для хранения. Каждый из них обрабатывает данные по собственным правилам и только для этой цели.

8. Как удалить свои данные

В приложении: Профиль → Изменить данные → Удалить аккаунт. Эта команда немедленно и без возможности восстановления удаляет с сервера всё: учётную запись, профиль и все результаты тренировок.

Прогресс, сохранённый локально на самом телефоне, при этом остаётся — он оттуда никуда и не уезжал, а телефон принадлежит вам. Чтобы стереть и его, удалите приложение.

Если доступ к приложению утрачен, напишите на адрес из раздела 11, указав электронную почту аккаунта Google, — данные будут удалены.

9. Дети и подростки

Приложение допускает указание возраста начиная с 10 лет, поскольку карате занимаются дети. Если пользователю нет 18 лет, вход в аккаунт и передачу данных на сервер следует выполнять с ведома и согласия родителя или опекуна. Без входа в аккаунт приложение полностью работоспособно и не передаёт никаких данных — это предпочтительный режим для младших пользователей.

Просьба об удалении данных ребёнка, направленная родителем или опекуном по адресу из раздела 11, исполняется без дополнительных условий.
