Mikey

Приложение для самостоятельных тренировок по карате. Считает повторения по изображению с камеры телефона.

Как это работает

  • Приложение показывает технику и объясняет, что делать.
  • Камера телефона следит за движением и считает повторения.
  • Прогресс сохраняется, чтобы вернуться туда, где вы остановились.
Изображение с камеры не покидает телефон. Распознавание позы целиком выполняется на устройстве: ни кадров, ни видео никуда не отправляется и нигде не сохраняется.

Аккаунт — по желанию

Без входа приложение работает полностью и не передаёт никаких данных. Вход через Google нужен ровно для одного: чтобы прогресс вернулся после переустановки приложения или при смене телефона. Удалить аккаунт вместе со всеми данными можно в самом приложении, одной кнопкой.

Состояние

Приложение находится в разработке. Функции меняются, работа сервера без перерывов не гарантируется.
